04速查手册：基础语法 / 流程控制

按"忘了一眼就能想起来"的标准写，建议打印出来放手边。Python 靠缩进分块，代码块里的注释别照抄，要自己敲。

基础语法

变量、类型、输入输出、格式化
# 输出与输入
print("Hello, 世界")
name = input("请输入名字：")   # input 返回的一定是字符串

# 变量：不需要声明类型，直接赋值
age = 18
height = 1.75
is_student = True        # 注意首字母大写
name = "张三"

# 类型转换
num = int("123")        # 字符串转整数
s = str(123)           # 整数转字符串
f = float("1.5")     # 转小数

# 格式化输出（f-string 最常用，推荐）
print(f"我叫{name}，今年{age}岁")
类型示例什么时候用
int18整数：年龄、数量、编号
float3.14小数：价格、成绩、比例
str"你好"文本：名字、地址、内容
boolTrue / False真假：是否登录、是否通过
NoneNone空值：表示"没有值"
两个高频错误：① input() 拿到的是字符串，做加法前要先 int() 转换；② Python 布尔值是 True/False（首字母大写），写 true 会报错。

运算符

算术、比较、逻辑
# 算术
a + b   a - b   a * b   a / b   a // b   a % b   a ** b
# 除 / 结果一定是 float；整除 // 取整；% 取余；** 求幂

# 比较：返回 True/False
a == b   a != b   a > b   a < b   a >= b   a <= b

# 逻辑
and   or   not       # 注意是英文单词，不是 && || !

# 赋值
x += 1    # 等价 x = x + 1

流程控制

if / while / for
# if 多分支：靠缩进分块，冒号不能少
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")

# while 循环：条件成立就重复
i = 1
while i <= 5:
    print(i)
    i += 1               # 别忘了让 i 变化，否则死循环

# for 循环：遍历序列，最常用
for i in range(1, 6):   # 1,2,3,4,5（不含 6）
    print(i)

for name in ["张三", "李四", "王五"]:
    print(name)

# break 跳出整个循环，continue 跳过本次
for i in range(10):
    if i == 5:
        break
    print(i)          # 打印 0~4
range 的口诀：range(起始, 结束, 步长)，取头不取尾。一个参数 range(5) 是 0~4； 两个参数 range(2,5) 是 2,3,4；倒序 range(5,0,-1)。

小练习：九九乘法表

for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j}", end="\t")
    print()   # 换行

05速查手册：容器 / 函数 / 文件异常

容器是 Python 的命根子，函数是让代码能复用的关键，文件异常是让程序能落地的最后一块拼图。

字符串 str

不可变，操作都返回新字符串
s = " hello world "
s.strip()            # 去首尾空格 → "hello world"
s.upper()            # 转大写
s.lower()            # 转小写
s.replace("world", "Python")
s.split(" ")           # 按空格切成列表
"-".join(["a","b"])   # 列表拼成字符串 "a-b"
s.find("world")       # 找子串位置，找不到返回 -1
s.startswith("h")     # 是否以...开头

# 切片：s[起点:终点:步长]，取头不取尾
s[0:5]    s[-3:]    s[::-1]    # 倒序

列表 list

有序、可变，最常用容器
nums = [3, 1, 2]
nums.append(4)        # 末尾加 → [3,1,2,4]
nums.insert(0, 9)      # 指定位置插 → [9,3,1,2,4]
nums.remove(1)        # 删第一个值为 1 的元素
n = nums.pop()         # 弹出并返回最后一个
nums.sort()            # 原地排序（升序）
nums.sort(reverse=True)
len(nums)             # 长度
3 in nums             # 是否包含 → True/False

# 列表推导式：一行生成列表，Python 特色
squares = [x*x for x in range(1, 6)]   # [1,4,9,16,25]
evens = [x for x in nums if x % 2 == 0]

元组 / 字典 / 集合

tuple 不可变，dict 键值，set 去重
# 元组：不可变，常用于固定组合、函数多返回值
point = (3, 4)
x, y = point          # 解包

# 字典：键值对，接口 JSON 的本质
stu = {"name": "张三", "age": 18}
stu["score"] = 90     # 加键
stu.get("name")        # 取值，键不存在返回 None（比 stu["x"] 安全）
stu.keys()  stu.values()  stu.items()
for k, v in stu.items():
    print(k, v)

# 集合：自动去重，做交集并集
a = {1, 2, 3}
b = {2, 3, 4}
a & b   # 交集 {2,3}
a | b   # 并集 {1,2,3,4}
set([1, 1, 2, 3])   # 去重 → {1,2,3}
字典取值用 get 而不是 []：键不存在时 stu["x"] 会直接报错崩溃，stu.get("x") 返回 None 更安全。这是新手写接口处理数据时最常见的崩溃原因。

函数

复用代码、拆分逻辑
# 基础定义
def add(a, b):
    return a + b

# 默认参数（有默认值的放后面）
def greet(name, greeting="你好"):
    return f"{greeting}，{name}"

# 关键字参数（可不按顺序传）
greet(name="张三", greeting="早上好")

# 可变参数 *args（任意个） / **kwargs（任意键值）
def total(*nums):
    return sum(nums)

# lambda 匿名函数
square = lambda x: x * x
默认参数的坑（面试常问）：默认值如果是可变对象（如 def f(x=[])），会在多次调用间共享同一个列表。 要写成 def f(x=None): x = x or []。这是新手必踩的坑。

文件操作与异常

让数据能保存下来
# 写文件（w 覆盖，a 追加）
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")

# 读文件
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()          # 读全部
    # lines = f.readlines()  # 读成列表

# json 读写（存结构化数据）
import json
data = {"name": "张三", "scores": [90, 85, 88]}
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False)
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)

# 异常处理：程序不崩溃
try:
    x = int(input("请输入数字："))
except ValueError:
    print("输入的不是数字！")
except Exception as e:
    print(f"出错了：{e}")
finally:
    print("无论是否报错都会执行")
with 的好处：用 with open(...) 会自动关闭文件，不用手写 f.close()，还能防止中途出错导致文件没关。 以后读写文件一律用 with。

06速查手册：面向对象 / 模块包

面向对象是把现实事物抽象成代码的思维方式，模块包是复用别人代码的入口。两者是"从小项目走向大项目"的门槛。

类和对象

class 是模板，对象是实例
# 定义一个"学生"类
class Student:
    # 构造方法：创建对象时自动调用，self 代表对象本身
    def __init__(self, name, age):
        self.name = name      # 实例属性
        self.age = age

    # 实例方法：第一个参数永远是 self
    def introduce(self):
        return f"我叫{self.name}，{self.age}岁"

# 创建对象（实例化）
stu = Student("张三", 18)
print(stu.name)            # 访问属性
print(stu.introduce())    # 调用方法
self 到底是什么：self 就是"当前这个对象自己"。你写 stu.introduce() 时，Python 会自动把 stu 传给 self，所以方法里能用 self.name 拿到这个对象的名字。 一句话：谁调用，self 就是谁。

继承与多态

复用父类，扩展子类
# 父类
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return "..."

# 子类继承父类
class Dog(Animal):
    def speak(self):              # 方法重写
        return f"{self.name}：汪汪"

class Cat(Animal):
    def speak(self):
        return f"{self.name}：喵喵"

# 多态：同一个方法名，不同对象不同表现
animals = [Dog("旺财"), Cat("咪咪")]
for a in animals:
    print(a.speak())

# super()：调用父类方法

class BankAccount:
    def __init__(self, balance):
        self.__balance = balance    # 双下划线开头 = 私有

    def get_balance(self):
        return self.__balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount

08新手最容易踩的 12 个坑

这些错误在课程作业和真实开发中反复出现，提前知道能省大量 debug 时间。

#错误写法 / 做法问题与正确做法
1缩进混乱 / 混用空格和 TabPython 靠缩进分块。统一用 4 个空格，别和 Tab 混用，否则报 IndentationError。
2input("请输入") + 1input 返回字符串，不能和数字直接算。先 int(input(...)) 转换。
3写成 true / falsePython 布尔是 True / False，首字母大写，否则当变量名处理报错。
4if a = 5 用单等号判断= 是赋值，== 才是比较。判断相等必须写 ==。
5stu["x"] 取不存在的键直接报 KeyError 崩溃。改用 stu.get("x") 返回 None。
6字符串与数字拼接"年龄" + 18 报错。用 f-string：f"年龄{18}"。
7for x in list: list.remove(x)遍历时删列表会漏删。用列表推导式重建，或遍历副本。
8def f(x=[]) 可变默认参数默认列表在多次调用间共享。改成 def f(x=None): x = x or []。
9while True: 忘写退出条件死循环。记得在循环体内写 break 或让条件能变 false。
10浮点数 0.1 + 0.2 != 0.3浮点精度问题。金额计算用 decimal，比较用 round 或误差范围。
11读文件不写 encoding="utf-8"中文乱码或报错。读写文本文件统一加 encoding="utf-8"。
12中英文符号混用中文引号 “”、中文冒号会报语法错误。敲代码全程用英文输入法。
最后一句建议：14 天结束后不要急着学框架。先用纯 Python 写一个完整小项目（比如把你的学习计划做成一个能增删改查的命令行程序）， 再进入 FastAPI + React + SQL 的后端主线。Python 是"写出来的"，不是"看出来的"。
