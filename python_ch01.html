核心概念与官方定义

Python 中的对象有身份、类型和值。类型决定对象支持哪些操作。整数 int 和字符串 str 不可变，字典 dict 可变。

简单名称赋值 name = expression 先求右侧表达式的值，再将左侧名称绑定到所得对象。再次对同一名称赋值会改变该名称的绑定。

字典是从可哈希的键到值的映射。本章用字符串作为字段名，把博文编号、所属事件、点赞数和正文放在同一条记录中。

底层原理 / 避坑指南

底层原理深潜 · 名称绑定与对象身份

运行 a = post 后，a 和 post 引用同一个字典，a is post 为 True。此时执行 a["likes"] = 99 会修改共享字典，经 post 读取也得到 99。

接着执行 a = {}，只有 a 改为绑定新字典。原字典的 likes 仍是 99。这是语言层的引用关系，同一段 Python 代码可以在不同解释器实现上验证。

常见报错避坑 · ValueError、TypeError 与业务边界
  • int("12次") 或 int("") 引发 ValueError。实际导入时应记录原值及拒绝原因。
  • int(None) 引发 TypeError。缺失值应在转换前单独处理。
  • int("-1") 成功返回 -1。点赞数要求非负，转换后还需做范围校验。
